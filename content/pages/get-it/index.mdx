Violentmonkey is built with WebExtension APIs. It supports a lot of browsers.

You can either install it from web stores or build from source code.

## WebExtension-compatible browsers

Chrome, Firefox 57+, Edge, Chromium, Brave, Cent, Orion, Opera 15+, Vivaldi, QQBrowser, etc.

**Note**

- **Opera users** please **install from Chrome Web Store** because the Opera team no longer reviews the extension because they think Violentmonkey is too complicated and they don't have time to review it. 😞

### Beta Release

The beta version is published more frequently than the stable release, with bug fixes and new features that will be included in the next stable release.
However it may have bugs and lead to data loss. Please **back up your data** and use it at your own risk.

### Test builds

Generated automatically for changes between beta releases. You can install them as an unpacked extension in Chrome and Chromium-based browsers or as a temporary extension in Firefox (to restore your main version simply restart Firefox). It's likely to have bugs so do an export in Violentmonkey settings first.

* [CI workflows](https://github.com/violentmonkey/violentmonkey/actions/workflows/ci.yml) (only for signed-in github.com users), open an entry in the list and click a `Violentmonkey-...` link at the bottom to download it.
* [nightly.link latest](https://nightly.link/violentmonkey/violentmonkey/workflows/ci/master?preview) (to download any other build replace `github.com` with `nightly.link` in the artifact URL)
